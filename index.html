The Sheet view puts worksheets of formulas next to the pivots and charts, reading the workspace's live data.

  • Formulas read every dataset of the workspace directly: DATASET.SUM, DATASET.LOOKUP, DATASET.ROWS and more.

Your extensions' tables and fields, too

Most companies run Business Central with apps and customizations. ALive Analysis sees their tables and fields like the standard ones.

  • Tables and fields that other extensions add, from AppSource apps or your own, appear in the Query Designer next to the standard ones.
  • Join them, filter them and total them like any other table.
  • Tables and fields an extension marks as internal are never offered: the extension keeps its own privacy decision.
  • Design and preview such a query on the Free plan; run your own workspaces with them on Pro.

When a query is not enough, a script

A dataset can also be a script written in AL syntax, the language of Business Central developers, for logic a visual query cannot express.

  • AL syntax with IntelliSense, run against your live data from the Studio.
  • Read-only and sandboxed: a workspace script cannot write data, post, commit or run codeunits.
  • Nine templates already use scripts, on the Free plan; write your own on Pro.

Your data stays in Business Central

ALive Analysis is an extension inside Business Central, not a service beside it. There is nowhere else for your data to go.

  • Rows go from the Business Central server to the user's page and nowhere else. There is no copy in another cloud.
  • Every run reads with the user's own Business Central permissions; each workspace is granted to permission sets.
  • Tables and fields an extension marks as internal are never offered.
  • Read-only by design: the analysis has no code path that writes business data.
  • Business Central telemetry holds counts and durations only, never a value, a filter or a name.
  • ALive Analysis makes no calls of its own to any server.
  • A file leaves only when a user exports it to Excel or CSV, under Business Central's own export permission.
  • The optional AI assistant receives definitions only, never a figure.

Permissions and access in the documentation

Pro + AI

An assistant that never sees your figures

ALive AI is a separate, optional app. Describe the analysis you need and it designs the workspace. It can also improve or explain a workspace and suggest views.

  • It works from metadata only: table and field definitions, never a row that a query, report or script returns.
  • Values inside an existing workspace or script are hidden behind placeholders before it is sent, unless you choose to send a script as written.
  • Your administrator chooses the AI provider and uses the company's own key, with monthly caps.
  • Every request is in a log you can read. A designed workspace opens unsaved, for a person to review.
