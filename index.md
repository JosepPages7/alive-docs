# ALive for Business Central

Help for the ALive apps for Microsoft Dynamics 365 Business Central. Each app is installed on its own; open the help of the app you use.

| App | What it does |
|---|---|
| [ALive Code](code/) | Write and run AL code directly inside Business Central, save it as programs, and browse data with the Data Explorer. |
| [ALive Analysis](analysis/) | Analyze Business Central data in workspaces (pivots, charts, KPIs) and spreadsheets, built with the Query Designer or sandboxed scripts. |
| [ALive AI](ai/) | An AI assistant that designs ALive Analysis workspaces and scripts. Only metadata is sent to the AI provider, never record values. |
