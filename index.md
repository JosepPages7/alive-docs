# ALive for Business Central

Help for the ALive apps for Microsoft Dynamics 365 Business Central. Open the help of the app you use.

| App | What it does |
|---|---|
| [ALive Code](code/) | Write and run AL code directly inside Business Central, save it as programs, and browse data with the Data Explorer. |
| [ALive Analysis](analysis/) | Analyze Business Central data in workspaces (pivots, charts, KPIs and a spreadsheet view), built with the Query Designer or sandboxed scripts. |
| [ALive AI](ai/) | An AI assistant that designs ALive Analysis workspaces and scripts. Only metadata is sent to the AI provider, never record values. |

## Three separate extensions

ALive Code, ALive Analysis and ALive AI are three separate Business Central extensions. Each one is installed on its own, and you can use an app only when it's installed in your environment:

- **ALive Code** and **ALive Analysis** don't depend on each other. Your organization can install either one, or both.
- **ALive AI** is an add-on for ALive Analysis. It can be installed only together with ALive Analysis, and its assistant appears in ALive Analysis pages.

If you can't find a page or an action that this help describes, check on the **Extension Management** page that the app is installed, or ask your administrator.
